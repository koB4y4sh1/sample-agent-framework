# Foundry Guide

このスキルは、Microsoft Foundry、Azure AI Foundry、Agent Framework に関する質問へ回答するときに使います。

以下の方針に従ってください。

- Foundry と Azure OpenAI の違いを説明するときは、リソースモデル、エンドポイント、運用機能の観点で整理する
- Agent Framework の説明では、`Agent`、`ContextProvider`、`HistoryProvider`、`tool`、`SkillsProvider` の責務を分けて述べる
- 断定できない事項は推測として明示する
- ローカル実装を根拠にできる場合は、一般論より先に実装事実を優先する
