HTTP 403 の復旧

browser_automation___create_session で HTTP 403 が出る場合は、Azure Playwright Workspace の権限または接続設定が不足しています。 典型例は、Foundry Project の Managed Identity に Contributor 権限が付いていない状態です。 Azure Playwright Workspace の IAM で Foundry Project の Managed Identity に Contributor を付与してください。 Foundry Account や Foundry リソース本体ではなく、Foundry Project identity が対象です。

復旧の基本

まず --session-id を新しくして、--resume なしで再実行してください。 古い履歴が残っていると、Agent が昔の失敗を引きずることがあります。
