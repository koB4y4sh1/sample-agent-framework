⑧ 付録：Foundry Toolbox と Playwright Workspaces

ブラウザを動かす「外部サービス」と料金の仕組み

この Harness のブラウザは、Foundry の Browser Automation Tool（Toolbox） と Azure Playwright Workspaces の 2 つで動いています。 それぞれの役割・セットアップ・料金形態をまとめます。

先に全体像

課金は 3 階建てです。Foundry Agent Service とツール自体は基本無料で、 実費は モデルのトークンと Playwright Workspaces のテスト分（test minutes）に乗ります。

A. Foundry の Toolbox（Browser Automation Tool）public preview

Foundry Agent Service が提供するツールの 1 つで、エージェントが自然言語でブラウザを操作するための MCP ツールです。ヘッドレスブラウザ基盤として Playwright Workspaces を使います。

仕組み

リクエストごとに隔離・サンドボックス化されたブラウザセッションを生成し、 「スクリーンショットで状態観測 → アクション（クリック / 入力 / 座標）」のループを、モデルが止めるまで繰り返します。 マルチターン対話・Live View デバッグ・human-in-the-loop（Take control）に対応します。

⚠ セキュリティ警告（公式が強調）

AI が認証情報を使って実ブラウザを操作するため重大なリスクがあります。信頼できるサイトのみで使い、付与する資格情報は最小限に。判断・テスト・責任は利用者側です。

制限

信頼サイト限定／ページ変動で壊れやすい／JS 重い SPA は描画できないことがある／処理が長くタイムアウトは 5 分以上推奨。

料金（Toolbox 部分）

Browser Automation Tool 自体・Foundry Agent Service 自体に追加料金はありません。 実費は モデルトークン ＋ 下層の Playwright Workspaces（test minutes） に発生します。

B. Azure Playwright WorkspacesGA（一般提供）

Playwright ベースのフルマネージド E2E テスト基盤。クラウド上の本物のブラウザを大規模並列で動かします。 Browser Automation Tool のブラウザ実行は、この Workspace 上で走ります。

名称の経緯（重要）

旧称 「Microsoft Playwright Testing」（preview） は 2026 年に retire され、 Azure App Testing 配下の 「Playwright Workspaces」に統合・GA 化されました。 古い名前のドキュメントや URL を見たら、これと同一のサービスです。

いずれかの上限を超えると、workspace は自動的に従量課金へ移行します（超過分のみ課金）。2 個目以降の workspace は最初から従量課金です。
