⑤ 長時間ループ

一回で全部やらせず、短い作業を何度も回します

長時間稼働のコツは、巨大な 1 回の実行にしないことです。この Harness は 「1 サイクルで少し進む」を繰り返します。

1 サイクルの動き

図 4-1 ｜ 5 ステップを繰り返すループ

プロンプト作成runtime.py の LOOP_PROMPT
→
Agent 実行次の小さい作業
→
結果パースLOOP_STATUS を読む
→
ログ保存jsonl / checkpoint
→
次を判断継続 / 停止 / 再試行

↻ CONTINUE なら「プロンプト作成」に戻り、次のサイクルを回す

ステータスの意味

ステータス意味次の動き
CONTINUEまだ続けられる。次サイクルへ進む。
COMPLETE依頼が完了した。終了コード 0 で止まる。
NEEDS_USERログイン・MFA・承認・追加入力が必要。人間待ちで止まる。
BLOCKEDツール・環境・対象サイトで詰まった。再試行または停止。

どこで止まるか

COMPLETE
成功して完了
NEEDS_USER

連続失敗
consecutive-error-limit
最大回数
max-cycles
最大時間
max-runtime-hours

BLOCKED のときの分岐

図 4-3 ｜ --unattended の有無で挙動が変わる

BLOCKED や停滞が起きた
→
--unattended あり 上限に達するまで回復を試し続ける（夜間稼働向き）
BLOCKED や停滞が起きた
→
--unattended なし 早めに止まる。検証時は原因を追いやすい

再開（resume）の仕組み

checkpoint.json に最後のサイクル結果が保存されます。 次回 --resume を付けると、その情報を LOOP_PROMPT に入れて再開します。
