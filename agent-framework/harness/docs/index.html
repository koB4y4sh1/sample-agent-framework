① 全体像から読む → ② HarnessAgent の仕組み

先に結論

この Harness は「AI が直接ブラウザを持っている」仕組みではありません。 次の一手を考える脳は Agent Framework の HarnessAgent が担当し、 実際にブラウザを動かすのは Python のツールです。役割を 5 つのレイヤーに分けて理解すると、 どこで何が起きているかが追えるようになります。

★ まず読むべき章

この Harness の頭脳は Agent Framework の create_harness_agent() が作る HarnessAgent です。 その構成（ChatClient・指示文・ツール・プロバイダ・ミドルウェア）と「二重ループ」の考え方は ② Agent Framework と HarnessAgent にまとめました。ここが核心です。
